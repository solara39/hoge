# 架空の物件候補リスト

`架空物件候補.csv` は、住まい候補比較ボードの操作感を試すためのサンプルです。

- 施設と候補物件の名称・所在地・緯度経度・価格・賃料・設備・災害リスク評価はすべて架空です。
- 地図上の位置は千葉市周辺を想定して置いたサンプル座標で、実在する物件の位置を示しません。
- 価格、改修費、賃料、築年、受入人数、売却見込みなどは市場調査に基づくものではありません。
- 実在物件の判断や事業計画には使用しないでください。

CSVの列は、画面の「一覧をCSV保存」で出力する形式に合わせています。将来、実際の物件データを取り込む際は、元データと出典・取得日を別途記録してください。
