# 空き家仕入れ台帳

> **重要：このツールは公開GitHub Pagesで配信されています。実運用前に、非公開の場所へ移してください。施設名・住所、所有者の住所・氏名、調査記録などを公開環境で扱わないでください。**
>
> ブラウザ内保存（localStorage）はその端末・ブラウザのプロファイル内に保存されるだけで、暗号化や端末間同期は提供しません。JSONバックアップにも同等の個人情報が含まれるため、保管場所と共有先を制限してください。地図タイル、ジオコーダー、Google Mapsへの通信は外部サービスへ送信されます。

## 概要

`prototype/property-comparison.html` は、従来の住まい候補比較機能を残した単一HTMLのツールです。新しい空き家仕入れ台帳では、施設CSVの取込、地図上での現地確認地点の記録、候補の進捗管理、JSONバックアップを行います。実データはHTMLやリポジトリに含めず、利用者が画面から取り込みます。

## 使い方

1. ページを開き、「施設CSVを取り込む」からUTF-8 CSVを選びます。必要な列は `法人名,施設名,住所,住所の出典,住居契約状況` です。
2. 施設住所は国土地理院の住所検索サービスで順番に座標化されます。住所の出典に「代用」が含まれる施設は点線ピンと「施設住所 未確認」で区別されます。
3. 施設セレクターで施設を選ぶと、地図と従来比較欄に施設名・住所が反映されます。地図上の右クリックまたはスマートフォンで長押しすると、地点のストリートビューを開くリンクと候補登録ボタンが表示されます。
4. 候補を登録し、確認理由・見た人・見た日、入口、所有者特定や手紙送付などのステータスを更新します。登記情報提供サービスは人が操作します。
5. 「JSON書き出し」でバックアップし、「JSON読み込み」で同じ端末または別の端末に復元します。

国土地理院の淡色地図の出典を地図下部に表示します。ハザードタイルは国土交通省の公開タイル仕様に基づき、洪水・急傾斜地崩壊・津波を切り替え表示します。地図上の色は参考情報であり、この段階では候補地点の画素判定をしません。

## 次段階のデータ準備

### 町丁目別の空き家調査件数（第2段階）

境界GeoJSONと集計CSVは画面外で準備し、将来のアップロード機能に渡します。実装で追加するデータは架空サンプルに限り、施設・所有者の実データはリポジトリに置かないでください。

1. e-Statの2020年国勢調査小地域境界データを対象市区町村で取得します。
2. Mapshaper等で対象自治体に絞り、GeoJSONに変換します。キーコードと町丁目名を保持し、座標系がWGS84（経度・緯度）であることを確認します。
3. 自治体の空き家実態調査から町丁目別の集計値を整理し、`KEY_CODE` または境界と一致する町丁目名、`空き家件数`、任意の `空き家率` をCSVにします。集計単位が境界と一致することを確認してください。
4. 最初の対象は千葉県香取郡多古町です。現時点で多古町境界・調査値データは同梱していません。

### 登記所備付地図（第3段階）

1. G空間情報センターで対象自治体の法務省登記所備付地図データ（XML）の公開状況を確認して取得します。
2. `mojxml2geojson` 等を使い、筆ポリゴンと所在・地番属性を保持したGeoJSONに変換します。
3. 変換元データの精度区分を確認してください。「地図に準ずる図面」等は位置の精度が低い場合があり、画面の地番候補を登記上の確定情報として扱わないでください。
4. 多古町データの提供状況は未確認です。アプリのアップロード機能も第3段階で実装します。

## ハザードタイル出典・仕様

国土地理院の「重ねるハザードマップ」オープンデータ仕様（[公式ページ](https://disaportal.gsi.go.jp/hazardmapportal/hazardmap/copyright/opendata.html)）で確認したテンプレートです。XYZタイル方式、ズームレベル2〜17です。

- 洪水浸水想定区域（想定最大規模）：`https://disaportaldata.gsi.go.jp/raster/01_flood_l2_shinsuishin_data/{z}/{x}/{y}.png`
- 土砂災害警戒区域（急傾斜地の崩壊）、千葉県：`https://disaportaldata.gsi.go.jp/raster/05_kyukeishakeikaikuiki_data/12/{z}/{x}/{y}.png`
- 津波浸水想定、千葉県：`https://disaportaldata.gsi.go.jp/raster/04_tsunami_newlegend_pref_data/12/{z}/{x}/{y}.png`

表示には公式ページへの出典リンクを付けています。画素読取のCORS可否は第2段階の実地確認が必要で、現時点では区域内の自動判定は未実装・未確認です。不動産情報ライブラリAPIへのフォールバックも未実装です。

## セキュリティ・公開前確認

- 実運用データは公開GitHub Pagesで使わず、認証・アクセス制御のある非公開環境へ移行してください。
- `data/raw/facilities_23.csv` はローカルの作業用ファイルとして `.gitignore` 対象です。コミット、HTMLへの転記、公開サンプル化をしないでください。
- `localStorage`へのアクセスは例外処理しますが、保存容量超過やブラウザ設定による失敗もあり得ます。JSONバックアップを定期的に作り、安全な場所に保管してください。
- ストリートビューはGoogle Maps公式URLを新しいタブで開くだけです。画像の埋込み、保存、自動解析は行いません。
- 登記情報の取得・所有者特定は利用者が手動で行います。
